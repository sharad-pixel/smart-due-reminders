# Animated Homepage Offering Cycle

## Goal
Cycle the homepage opening between Recouply.ai’s original collections platform offering and the O2C Transformation offering without changing either destination or the rest of the page.

## Implementation
- Convert the existing homepage opening into a two-slide animated sequence.
- Give each slide its own headline, supporting copy, and primary destination.
- Use a smooth fade-and-rise transition with a clear two-position selector so visitors can switch immediately.
- Pause automatic cycling while a visitor hovers or focuses on the opening content, and respect reduced-motion preferences.
- Keep Start Free and Sign In available in both states.
- Preserve the existing semantic color system, mobile layout, and page content below the opening.

## Validation
- Confirm both offerings rotate and can be selected manually.
- Confirm all buttons navigate to the existing destinations.
- Check the opening at desktop and phone widths with no text or control overlap.
